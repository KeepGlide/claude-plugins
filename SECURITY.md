# Security policy

## Supported versions

The catalog has no version number yet. The supported version is the catalog on `main`.

| Version | Supported |
| ------- | --------- |
| `main` (the catalog as published) | ✅ |
| Earlier commits of the catalog | ❌ |

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Report it privately to [hello@keepglide.com](mailto:hello@keepglide.com) with the subject `Security: KeepGlide claude-plugins`. Include the commit or plugin version, the steps to reproduce and the impact you expect.

A vulnerability in a plugin belongs to that plugin's repository: [KeepGlide/askaway](https://github.com/KeepGlide/askaway) or [KeepGlide/master-jev-hook](https://github.com/KeepGlide/master-jev-hook).

## Response time

We acknowledge a report within 7 days and aim to publish a fix or a mitigation within 30 days, depending on severity.
